## v0.4.0 — 2026-10-10

Windows、Python 3.12，本地自动测试 **58 passed**。真实 MCP stdio 子进程完成十一个工具的发现和调用，以及三个提示词的发现；历史/资料提取提示词可读取。

- 多 Agent 同库来源区分；并发同消息重复提交只保存一份；角色变化与消息编辑保留独立证据版本。
- 新增/修改消息使会话检查点失效，过期指纹被拒绝；资料版本变化同样要求重新提取。
- 用户陈述不能仅用 AI 回复作为依据；AI 推测经过批准仍保留推测类型；更新继承旧来源。

- 文件、思考与事务可查询提取状态；文字 PDF/DOCX 解析、无文字/加密/损坏/超限文件拒绝。
- 同文不同文件保留独立来源；预览不写入，确认后才保存；提取草稿不自动进入正式档案。
- CLI 分析包限定 ID、拒绝覆盖已有文件；HTTP 预览导出保留来源，拒绝跨来源请求和非布尔受限授权。

真实浏览器验证：跨 Agent 会话及资料状态、分析资料选择与 JSON 预览、页面切换；1440px 桌面与 390px 移动视口，未发现横向溢出，控制台无错误。演示均为虚构资料。
