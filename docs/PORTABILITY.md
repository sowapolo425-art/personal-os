# 导入、备份与恢复 · v0.4

## 一键启动与迁移

Windows 双击 launch.cmd；macOS/Linux 运行 python3 scripts/launch.py。先安装 Python 3.11+，首次安装依赖需要网络。资料库由用户主动选择，必须位于项目目录之外。取消选择不会创建资料库。

启动器在 .local/launcher.json 记住目录，不上传或提交这个文件。切换目录用 --choose；无图形界面可用 --vault 指定绝对路径。移机后选择复制过去的完整资料库，再在面板生成新环境的 MCP 配置；旧的 Python 和磁盘路径不能直接照搬。

## 导入支持哪些格式

1. UTF-8 .md / .txt：每个文件作为一条知识资料，正文保留原内容。单条正文最多 100000 字符。
2. ChatGPT conversations.json：每条对话一条资料，沿 current_node 的父节点选择当前分支，不混合多个重生成分支。
3. 通用 JSON：形如 {"title":"对话名","messages":[{"role":"user","content":"原文"},{"role":"assistant","content":"回复"}]}；也支持多条此类对话的数组或 conversations 容器，以及 role/content 消息数组。

4. 文字 PDF / DOCX：PDF 最多 200 页，保留页码来源标题；DOCX 提取正文/表格段落。长正文拆成最多 100000 字符的片段。原文件与嵌入附件不复制，扫描件需另行 OCR。

只处理文字；附件、图片、工具消息、系统消息、analysis/commentary 不导入。助手回复明确标记为 AI 生成。当前不保证能直接解析所有品牌或未来版本的导出格式。

单文件最多 8 MB，最多 500 条对话，每条正文最多 100000 字符；超过则整体预览失败，要求拆分，不静默截断。Markdown/TXT 的标题或对话标题最多保留 300 字符，原始正文仍完整保留。

## 先预览，再保存

浏览器选择文件后传给本机服务处理，没有发往云端。预览只保留在当前进程内存中，30 分钟过期，服务重启后需重新选择；最多保存最近 4 次预览。

勾选要保留的资料并确认可见性。默认 restricted，仅面板主动显示时可见，Agent 默认不能检索。选择 private 后，已连接的 Agent 可以读取。

导入统一存入知识模块，status 为 imported_source。它不是稳定人格判断，也不意味着所有对话说法已确认。有效原始创建时间保留在时间线，未知日期使用导入日期。积累图统计真正导入到资料库的时间。

重复判断按来源文件名及正文 SHA-256，统一 CRLF 换行。同文件名同正文重复导入跳过；不同文件名保留独立来源，即使文字相同。不是语义去重，删改文字后的新版本仍可能作为新资料导入。已删除的当前记录可以重新导入。

批量导入使用库级锁和逐文件写入，不是多文件数据库事务；突然中断可能已保存部分记录，重新预览导入会依据正文去重。

## 完整备份

面板的“备份与恢复”下载包含受限资料、草稿、历史和审计的 ZIP。备份是明文，保存到自己控制的磁盘或加密存储。运行锁、.git、.venv、__pycache__ 和保留的备份清单文件名不打包。备份在读写锁下取得一致的工具管理状态；手工编辑不受锁保护，请备份前停止手工写入。

ZIP 内含 personal-os-backup.json，逐文件记录长度和 SHA-256。它检查文件完整性，不是数字签名，不能证明未知备份来源可信。仅恢复自己生成且来源可信的备份。

限制：压缩后最多 32 MB，原文件合计最多 128 MB，最多 5000 个文件。初版是轻量个人资料备份，不适合大量视频、图片或数 GB 的资料库。

命令行也可执行：

```powershell
.venv\Scripts\python.exe -m personal_os.cli --vault D:\PersonalData\my-vault backup --output D:\PersonalBackups\my-vault.zip
.venv\Scripts\python.exe -m personal_os.cli --vault D:\PersonalData\my-vault restore-backup D:\PersonalBackups\my-vault.zip
```

输出备份文件必须位于资料库外，已存在文件不会覆盖。

## 恢复到独立资料库

选择本项目生成的 ZIP，先验证格式、全部文件和校验值，拒绝路径穿越、符号链接与重复路径。验证失败不创建恢复库。验证通过后，在当前库旁创建 名称-restored-随机ID 的独立目录。

当前记录不会覆盖；恢复结果会显示新路径。要使用恢复库，重新启动选择新目录，并更新 Agent 接入配置。初版不自动切换当前服务，也不把旧备份直接覆盖到活动库。
