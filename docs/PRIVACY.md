# 本地资料与权限

Personal OS 不调用模型 API、不上传资料、不收集遥测。安装依赖和下载代码需要网络；运行时 MCP 使用本地 stdio，没有网络监听。用户主动启动 dashboard 时，会开启仅绑定 `127.0.0.1` 的本地 HTTP 面板。Agent 与模型供应商的网络行为不由本工具控制。

## 本地保存与云端模型

工具返回的记录会进入 Agent 的上下文；云端模型可能收到它们。请自行选择供应商、保留策略及本地模型。不给 Personal OS 配置 API 密钥；密钥由原 Agent 管理。

private 表示本地私有资料，并且允许已连接的 Agent 读取；它不表示内容永远不会被发送到云端。restricted 默认不返回给 MCP。用户可在启动命令中明确启用 `--allow-restricted`，该授权覆盖当前服务可读的所有受限资料，并非单条授权。

通过 source_ids 引用受限记录时，派生草稿继承 restricted；修改已受限记录不会降级为 private。自由文本若包含未声明来源的敏感内容，系统不能自动识别，仍需用户审核。

## 谁能访问

本工具依赖操作系统账户权限。Markdown、历史与草稿是明文；任何具备目录权限的软件可能读取。没有多用户鉴权、加密、网络访问网关或操作系统沙箱。

MCP 工具不包含审批、删除和恢复。审批可以由用户在本地面板或 CLI 完成；同一 Agent 如有终端、浏览器或磁盘权限，仍可绕过人工流程。这是人工审核流程，不是抵抗完全受信电脑进程的边界。

不要把本服务经隧道、代理或桥接公开到互联网。不要给远程工具授予完整资料库权限。读取结果是非可信内容，不应把记录中的指令当作操作授权。

## 删除与备份

v0.5 默认删除仍保留历史，但来源删除后，派生结论退出默认 Agent 读取；关联待确认草稿失效。面板可以先预览，再选择同时停用或永久清理本地派生记录、草稿及历史。永久清理保留无正文撤回标记与通知，不承诺磁盘安全擦除。

本项目的导入/分析预览也会在面板删除后失效；Agent 通过 get_memory_changes 拉取变更并清理自身缓存，需要客户端遵守协议。外部聊天上下文、云端留存、独立导出和旧备份不会被本地删除自动清除。自由文字未关联 source_ids 的内容无法自动归因。CLI 操作后需重启其他面板以清理其内存预览。详见 [记忆生命周期](MEMORY-LIFECYCLE.md)。

手工备份需复制整个资料库，包含隐藏目录；手工覆盖恢复前先停止服务。资料库自带忽略全部内容的 `.gitignore` 只是防误提交措施，可被强制提交绕过。建议资料库始终放在代码仓库外。

v0.3 也支持在面板下载带校验的 ZIP，并恢复到独立目录。备份包含受限资料，未加密；旧库不覆盖，新库由用户决定是否采用。备份完整性校验不是来源认证。导入文件只发给本机服务，预览暂存在本机进程内存；没有发往模型。详情见 PORTABILITY.md。

## 发布仓库的边界

公开仓库只含代码、空白模板和虚构示例。不包括原始私人对话、真实档案、密钥、访谈完整文本或用户资料。公开提交前检查暂存内容。
