# 路线图

## v0.1 已实现

本地 Markdown 主库、四个 MCP 工具、证据 ID、待确认修改、CLI 审批、文字检索、版本恢复、受限记录默认隐藏、最少审计、通用接入说明。

## 后续方向，尚未实现

- 在用户选定的 Codex / Claude Code / ZCode / WorkBuddy 版本中逐一验收。
- 扩展历史资料导入格式、附件处理和批量来源核对。
- 删除与派生资料清理、密钥管理、加密存储和加密备份。
- 可选本地检索索引、语义检索与数据格式迁移。
- 对仅支持 HTTP 的 Agent 提供有访问控制的本地桥接。
- 在单人本地架构上探索细粒度访问和工具权限。

保持模块可选、模型可更换、资料可迁移。未来数字分身是研究方向，不是当前功能。

## v0.2 已实现

本地浏览器面板：资料总览、分布与七天计数、文字搜索、时间线、来源与版本查看、草稿对比和审核、本人原文录入。资源随 Python 包提供，支持窄屏；只绑定回环地址，无集中托管。

## 面板后续优化方向

删除管理、目标进度字段和独立安装包。优先改善启动与资料导入体验，再做复杂的 AI 分析展示。

## v0.3 已实现

Windows 一键启动脚本、首次选库与环境安装、记住资料库、导入预览与正文去重、ChatGPT 当前分支/通用 messages JSON/MD/TXT 文字导入、完整性校验备份、恢复到独立目录、真实证据引用关联图、生成并复制接入配置。

后续可做：正式应用安装包、更多导出格式、图片/附件导入、加密备份、大资料库索引与分页、目标进度字段。当前启动器仍需要 Python，备份没有加密。
